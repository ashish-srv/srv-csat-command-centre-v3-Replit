# n8n workflows

The import-ready monthly-feedback workflows are generated by
`scripts/build-n8n-import-package.mjs`. The `workflows-v1-reference` exports are
source references only and should not be imported as the live v2 workflows.

Workflow 01 uses two different kinds of Meta secrets:

- `Meta WhatsApp Token` credential: outgoing Graph API calls.
- `META_APP_SECRET`: local HMAC verification of incoming POST webhooks.
- `META_VERIFY_TOKEN`: Meta's one-time GET webhook handshake.

The two Security Config nodes are local Set operations. They do not call Meta or
verify credentials over the network on every message. The POST HMAC check is
kept because otherwise any caller could forge a WhatsApp webhook. The workflow
acknowledges Meta before the slower CSAT/Gemini and WhatsApp-send steps.
`Call CSAT Engine` has a 45-second safety timeout, while the app bounds the
actual Gemini work and runs terminal tone/prediction/issue reads in parallel.
The larger n8n timeout is headroom, not an intentional response delay.

Workflow 02 sends the monthly feedback request by WhatsApp only. Workflow 06 is
the optional email-only fallback and should remain inactive unless email sending
is intentionally enabled.

Workflow 11 receives a dashboard-written message, sends it as free text through
the existing `Meta WhatsApp Token` credential, and returns only after Meta
accepts the send. Set `N8N_MANUAL_MESSAGE_WEBHOOK` in Netlify to its production
webhook URL. WhatsApp permits this free-text route only within 24 hours of the
client's latest message; the app enforces that window before invoking n8n.

Workflow 05 sends `srv_final_rating_reminder` for reminder three when a partial
respondent has not supplied an overall rating. Reminders one and two and all
no-response reminders retain their existing templates.

Workflow 12 sends `srv_feedback_session_closed` after an exhausted partial
session's final 24-hour grace period. Set
`N8N_FEEDBACK_SESSION_CLOSED_WEBHOOK` in Netlify to its production webhook URL.
The workflow waits for Meta to accept the template; only then does the app close
the session. **Stop Feedback** does not invoke this workflow.
